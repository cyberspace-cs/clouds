# Research Skills Map · 科研技能分类地图

一份把**科研全流程 Skills** 按「环节」与「来源仓库」双维度归类的速查地图，覆盖从选题到投稿的完整闭环。配套可视化报告见同目录 `科研Skills分类调研.html`。

## 何时用这个 Skill

- 用户问"有哪些科研类 Skill""科研流程用什么工具"
- 需要在某个科研环节（选题 / 文献 / 实验 / 绘图 / 写作 / 投稿）挑选合适的 Skill
- 想把新发现的科研 Skills 归到正确的环节与仓库分类下

## 分类维度一：按科研环节（7 大闭环）

| 环节 | 包含的 Skill |
| --- | --- |
| 1️⃣ 选题 | Supervisor Deep Research、Socratic Deep Research |
| 2️⃣ Idea 验证 | Idea Evaluator、ResearchStudio-Idea |
| 3️⃣ 文献检索与精读 | USTC Academic-Search、Nature Academic Search、Nature Reader、Nature Paper Card |
| 4️⃣ 实验设计 | Nature Proposal Writer、Academic Pipeline |
| 5️⃣ 科研绘图 | Nature Figure、Figure Designer、Draw.io 流程 |
| 6️⃣ 论文写作 | Paper Writer、Academic Paper |
| 7️⃣ 投稿返修 | Ref Verifier、Pre-Submission Reviewer、Nature Response |

## 分类维度二：按来源仓库

- **Nature Skills（7）**：Nature Academic Search / Nature Reader / Nature Paper Card / Nature Proposal Writer / Nature Figure / Ref Verifier / Nature Response
- **Supervisor-Skills（4）**：Idea Evaluator / Figure Designer / Paper Writer / Pre-Submission Reviewer
- **Academic Research Skills（2）**：Academic Pipeline / Academic Paper
- **其他 / 未明确来源（5）**：Supervisor Deep Research / Socratic Deep Research / ResearchStudio-Idea / USTC Academic-Search / Draw.io 流程

## 完整清单（18 个）

详见 `科研Skills分类调研.html`（含每个 Skill 的核心功能、所属环节、来源对照表）。

## 使用建议

1. **不要追求完美顺序**：科研不是线性流程，可按需跳跃使用各环节。
2. **同类技能择优**：每个环节有 2–3 个可选 Skill，按"时间紧张度 + 严谨度要求"选择。
3. **输出复用**：每个环节的输出（文献卡片、实验计划）可作为后续环节输入。
