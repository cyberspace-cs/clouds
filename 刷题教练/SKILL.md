# 刷题教练

## 目标

把"刷题"变成"有路线的能力提升"：先定路线，再逐题精讲，最后用遗忘曲线复习。

## 核心流程

### 1. 摸底定制

- 明确三件事：当前水平（零基础 / 刷过 N 题 / 竞赛选手）、目标（面试算法题 / 系统提升 / ACM）、可用时间（每周几小时、共几周）。
- 无信息时给默认方案：8 周从零到面试，每天 1-2 题。

### 2. 路线设计（分层递进）

| 阶段 | 主题 | 代表题 |
|---|---|---|
| 1. 基础 | 数组/字符串/哈希 | 两数之和、最长无重复子串 |
| 2. 线性结构 | 链表/栈/队列 | 反转链表、有效的括号 |
| 3. 树与递归 | 二叉树遍历/DFS/BFS | 二叉树中序遍历、层序遍历 |
| 4. 进阶搜索 | 回溯/二分 | 全排列、搜索旋转排序数组 |
| 5. 动态规划 | 一维/二维/背包 | 爬楼梯、最长公共子序列 |
| 6. 图论 | 拓扑/最短路/并查集 | 课程表、岛屿数量 |
| 7. 专项 | 贪心/滑动窗口/堆 | 合并区间、前 K 高频元素 |
| 8. 面试冲刺 | 高频题+模拟面试 | 按公司题库刷 |

- 每阶段给出：5-10 道必做题 + 2-3 道挑战题；标注时间复杂度要求。

### 3. 单题讲解模板

```markdown
## 题目：<名称>（难度）
**考察点**：数据结构 / 算法思想
**思路**：
1. 暴力解法（说清楚为什么不行）
2. 优化点（空间换时间 / 双指针 / 状态压缩）
3. 最优解法步骤
**复杂度**：时间 O(?) 空间 O(?)
**代码**：<语言实现，含注释>
**易错点**：边界 / 空值 / 越界
**同类题**：<2-3 题>
```

### 4. 复习机制

- 使用间隔重复：当天错题、3 天后、1 周后、1 月后各重做一次。
- 维护错题本：每题记录"卡住的点 + 突破思路"，不抄代码。
- 每周一次"盲写"：不看题解默写 3 道本周题的完整解法。

## 检查清单

- [ ] 路线按用户水平/时间定制，不套模板
- [ ] 每道讲解包含复杂度分析与同类题推荐
- [ ] 给出可执行的每日/每周计划表
- [ ] 有复习与错题机制说明
- [ ] 代码可以本地运行验证（提供测试用例）
