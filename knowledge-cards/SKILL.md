# 知识卡片

## 目标

把一篇文章或学习材料转换成 5~8 张知识卡片，每张卡片只讲一个知识点，可直接用于复习与分享。

## 输入

- 必需：文章全文（粘贴文本）或本地 Markdown/TXT 文件路径。
- 可选：卡片数量偏好（默认 5-8 张）、主题侧重、语言。

## 暂不支持

- 网页抓取、PDF、Anki 导出、图形界面。

## 工作流

### 1. 提取真正重要的知识

- 通读全文，识别：核心概念、关键定义、重要机制、易错点、可操作结论。
- 忽略：客套话、背景铺垫、重复表述、与主题无关的细节。

### 2. 生成卡片（每张只讲一个知识点）

每张卡片固定四要素：

```markdown
### 卡片 N：<标题>
**核心知识**：<一句话说清这个知识点>
**简明解释**：<2-4 句展开，让人真正理解>
**例子或自测问题**：<一个真实例子，或一个能让读者自测的问题>
```

### 3. 质量控制（硬性要求）

- 一张卡片只讲一个知识点，不合并、不拆分。
- 删除重复内容：多个段落讲同一件事，只保留最清晰的一版。
- 不能编造原文没有的信息；不确定的标注"原文未说明"。
- 信息不足时不要强行凑数量：少于 5 张有价值卡片，就输出实际能支撑的数量并说明。

### 4. 输出格式

- 输出完整 Markdown，从 `# 知识卡片：<主题>` 开始。
- 卡片按逻辑顺序排列（从基础到进阶，或按原文结构）。
- 结尾附一行"来源：<原文标题或文件>"，不虚构来源。

## 检查清单

- [ ] 卡片数量在 5-8 张（或如实说明不足）
- [ ] 每张卡片四要素齐全
- [ ] 每张卡片只讲一个知识点
- [ ] 无重复内容、无编造信息
- [ ] 有例子或自测问题，可直接使用
