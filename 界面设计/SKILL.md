# 界面设计

## 目标

让任何页面产出达到"专业设计师验收"标准：清晰的层级、克制的配色、一致的语言、可用的交互。

## 核心设计原则

1. **层级优先**：先定信息优先级，再定视觉权重。一屏只突出一个主操作。
2. **一致性**：颜色、圆角、字号、间距、阴影建立 token 体系，全站统一。
3. **留白是设计**：宁少勿多，控制信息密度；元素间距遵循 4/8 的倍数。
4. **克制用色**：主色 1 种 + 中性色为主 + 强调色 1-2 种；避免大面积紫/高饱和撞色（除非品牌要求）。
5. **文字可读**：正文 ≥14px，行高 ≥1.5；中文字体优先系统字体栈（`-apple-system, "PingFang SC", "Microsoft YaHei"`）。

## 设计系统建议

| 维度 | 建议值 |
|---|---|
| 主色 | 品牌 1 色（如 `#4F46E5`），hover 提亮、active 压暗 |
| 中性色 | 背景 / 表面 / 边框 / 次要文字 / 主要文字（灰阶 5 档） |
| 字号 | 12 / 14 / 16 / 20 / 28 / 36（px），标题用 20+ |
| 圆角 | 4 / 8 / 12（小中大） |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 |
| 阴影 | 2 档：卡片浮起 / 弹层浮起 |

## 组件规范要点

- **按钮**：主按钮（实心主色）、次按钮（描边）、文字按钮三级；禁用态明确（低对比+禁点）。
- **卡片**：圆角 8-12，浅阴影，hover 微提（阴影加深 1 档）；卡片内不堆多列按钮。
- **表单**：label 在上、输入框在下；错误提示就近显示；必填标记清晰。
- **表格/列表**：表头固定可辨识，行 hover 高亮，长文本省略+完整 tooltip。
- **导航**：当前项高亮；移动端用底部 tab 或抽屉，触控目标 ≥44px。
- **空状态/加载**：必须有（骨架屏或 loading 态），不能白屏等待。

## 实现检查（交付前逐项过）

- [ ] 页面有明确的视觉层级，主操作一眼可见
- [ ] 配色不超过主+中性+强调的限制，对比度达 WCAG AA（正文 ≥4.5:1）
- [ ] 字号/间距/圆角全局一致，使用 token 而不是散落魔法值
- [ ] 移动端与桌面都验证过布局
- [ ] 交互态齐全：hover / active / focus / disabled / loading / 空态
- [ ] 未使用大块高饱和色块，默认不选用紫色主题
